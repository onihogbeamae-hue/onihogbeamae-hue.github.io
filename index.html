C PROGRAMMING

Student Calculator

Problem: Students need a simple program to calculate two numbers and display their results. Calculating manually may take more time and can lead to mistakes.

Solution: I created a Student Calculator using C programming. The program asks for the student's name, section, and two numbers. It calculates the sum, difference, product, and quotient of the two numbers. It also checks if the second number is zero before performing division to avoid dividing by zero.

Tools Used: C Programming Language | Code Editor | C Compiler | Standard Input/Output Library (stdio.h)
